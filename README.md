TaskyXPz
TaskyXPz is a simple gamified task manager built with HTML, CSS, and JavaScript.

The project was developed to practice fundamental front-end development concepts, including DOM manipulation, event handling, local storage, and project organization. Users can create tasks, complete them, and earn XP points as a way to track progress and stay motivated.

Features
Create and manage tasks
Mark tasks as completed
XP-based progress tracking
Weekly XP progress bar
Local storage persistence
Responsive user interface
Technologies Used
HTML
CSS
JavaScript
